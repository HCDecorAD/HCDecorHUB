# Early Use scope

Available now:
- detect managed ChatGPT conversations;
- bind/unbind aliases;
- ONLINE/OFFLINE visibility;
- persistent queue dry-run;
- per-chat pause/resume;
- STOP ALL;
- diagnostics, watchdog, backup, rollback, migration and status reports.

Not enabled:
- real prompt submission;
- automatic autonomous worker control;
- production G2 routing.

This separation allows daily operational use while the upgrade branch continues safely.
