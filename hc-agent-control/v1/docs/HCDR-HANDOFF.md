# HCDR handoff

Latest verified HCDR V1.1 health is healthy in PROJECT mode, but its configured root may not contain HC_AutoChat.

Do not bypass the workspace guard. Once HCDR_V11_ROOT is legitimately configured to D:\HCDecorHUB or D:\HCDecorHUB\HC_AutoChat, run scripts\89_HCDR_HANDOFF_ACCEPTANCE.bat from the project.

The handoff runs automated RC acceptance and launches the demo. It does not enable Real Send and does not promote CP1/G2 by itself.
