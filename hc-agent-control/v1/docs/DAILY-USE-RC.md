# Daily Use RC

Run scripts\76_DAILY_USE_RC_QA.bat before promoting a v1-next build to the Early Use baseline.

Daily start: scripts\74_DAILY_START.bat.
Daily backup: scripts\78_DAILY_BACKUP.bat.
Reset onboarding: scripts\77_RESET_FIRST_RUN.bat.

The RC includes first-run guidance, Windows DPI awareness, queue filtering/history, retry/cancel controls, STOP ALL/Resume All and persistent theme/window settings.

Real Send remains outside this RC until G2 acceptance.
