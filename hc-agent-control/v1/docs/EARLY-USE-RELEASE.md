# HC Agent Control V1 — Early Use Release

Purpose: put V1 into daily use early for discovery, alias binding, monitoring, queue dry-run, STOP ALL, diagnostics, recovery and operational workflow.

Real ChatGPT Send remains disabled until G2 live targeted-send acceptance passes.

## Install/use
1. Build with scripts\59_PACKAGE_EARLY_USE.bat.
2. Copy dist\HC-Agent-Control-V1-EarlyUse to the desired local folder.
3. Run START_HC_AGENT_CONTROL.bat.
4. Use CONTROL_MENU.bat for diagnostics, backup and tests.

## Upgrade protection
Every Early Use package first creates a separate upgrade-baseline backup. Preserve that baseline for later V1 updates and V2/V3 development.

Early Use is not equivalent to Production gate PASS.
