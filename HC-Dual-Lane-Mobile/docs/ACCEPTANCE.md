# Acceptance gates
P1: APK artifact installs and launches.
P2: runtime permission + MediaStore read on real Samsung.
P3: create/copy/move/rename verified on real files.
P4: trash/restore + audit verified; permanent delete guarded.
P5: device/capability discovery + ECO/ACTIVE/TURBO verified.
P6: authenticated pairing, queue resume, idempotency.
P7: local Mobile-PC transfer verified.
P8: HOCUONG heavy job route + ADB/scrcpy adapter verified.
P9: iMaster target routing + fallback verified.
P10: full E2E, reconnect, PC-off direct-mobile survival, release APK.

No phase may be marked PASS from stub/echo tests.
