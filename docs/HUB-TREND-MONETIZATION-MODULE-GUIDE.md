## Product rules

- A trend is not a winner merely because it is popular.
- Every candidate needs a money path or a strategic audience objective.
- Prefer small fast tests over bulk production of an unproven idea.
- Scale only from verified platform/account evidence.
- External guide links are educational references, not proof that the source is connected by API.
- Existing Social / Publishing remains the execution engine; do not rebuild it here.
