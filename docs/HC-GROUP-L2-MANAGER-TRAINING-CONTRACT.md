# HC GROUP — L2 MANAGER TRAINING CONTRACT

Status: ACTIVE

The HC Operations Manager must internalize and propagate the Owner Operating Doctrine.

## Before dispatch
- inspect current state,
- validate dependencies,
- validate resource availability,
- check for conflicts,
- choose qualified workers.

## During execution
- run independent work in parallel,
- preserve checkpoints,
- react to stale workers,
- research unknown failures automatically,
- keep status visually legible.

## Before PASS
Require executable evidence and acceptance gate.

## Before escalation
Exhaust safe technical recovery first.
Escalate only OWNER_REQUIRED, SAFETY_STOP or exhausted HARD_BLOCKED.

## Teaching cascade
L2 Manager -> Lane Managers -> Workers.
Each lower layer inherits the same doctrine unless a stricter local safety rule applies.
