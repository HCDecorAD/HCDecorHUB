# HCDecor Design System v1

## Visual
- Nền chính: #090B0D
- Panel: #111417
- Accent bronze/gold: #D59A55
- Text: #F3F1ED
- Muted: #A6ADB3
- Radius mặc định: 16px
- Max content width: 1240px

## Trang chủ
1. Header: HCDecor HUB + menu + VN/EN + CTA.
2. Hero: ảnh công trình lớn, eyebrow HCDECOR HUB, H1 ngắn, CTA.
3. Dịch vụ: Bảng hiệu / Nội thất / 3D & Phối cảnh / Kiến trúc.
4. Dự án: portfolio có category.
5. Quy trình: 5 bước.
6. Giới thiệu.
7. Contact/lead form.
8. Footer + Facebook/TikTok/YouTube/Zalo.

## Responsive
- Desktop >= 1025
- Tablet 768–1024
- Mobile <= 767
- Mobile ưu tiên ảnh, heading gọn, CTA dễ chạm.
