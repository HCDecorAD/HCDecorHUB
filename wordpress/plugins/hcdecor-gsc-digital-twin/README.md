# GSC Digital Twin WordPress module

Interactive implementation derived from the verified GSC.Web configuration:
- 11 hotspot coordinates preserved.
- Hotspots 1–10 use their existing Google Drive video IDs.
- Hotspot 11 remains intentionally empty because the source configuration has no video.
- Responsive modal viewer with explicit close button.
- Shortcode: `[gsc_digital_twin]`.

This module is staged in the migration branch and is not claimed as live until installed/activated on WordPress.
