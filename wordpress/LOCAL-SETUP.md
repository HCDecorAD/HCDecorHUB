# Local setup — HCDecor Hub

Khi Local hoàn tất:
1. WP Admin → Appearance → Themes → Add New → Hello Elementor → Install/Activate.
2. Plugins → Add New → Elementor Website Builder → Install/Activate.
3. Copy thư mục `wordpress/hcdecor-core` vào `app/public/wp-content/plugins/`.
4. WP Admin → Plugins → HCDecor Core → Activate.
5. Settings → Permalinks → Post name → Save.
6. Pages → Trang chủ → Edit with Elementor.

HCDecor Core sẽ tự tạo các trang, taxonomy dự án và 4 dịch vụ nền.
