# HCDecor Elementor Build Plan v1

## Global
Theme: Hello Elementor
Builder: Elementor Free
Content/API: HCDecor Core
Production hiện tại không thay đổi cho đến cutover.

## Homepage
1. Header — logo HCDecor HUB, menu, VN/EN, CTA Liên hệ.
2. Hero — full-width image, eyebrow, H1, lead, 2 CTA.
3. Services — 4 image cards: Bảng hiệu / Nội thất / 3D & Phối cảnh / Kiến trúc.
4. Projects — visual portfolio, category-first.
5. Process — 5 steps.
6. About — short brand story + capability metrics.
7. Lead — phone/Zalo + project enquiry.
8. Footer — address/social/contact.

## Elementor responsive
Desktop content max-width 1240px.
Tablet: 2-column cards.
Mobile: 1-column visual cards, CTA ≥44px, compact typography.

## Content ownership
WordPress stores Projects/Services.
Elementor owns layout.
HCDecor Core owns data schema/API.
HCDecor HUB consumes/publishes data later.
